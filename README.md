# EduLink Congo — pages légales

Ce dépôt héberge, via GitHub Pages, les deux documents légaux publics d'EduLink Congo :

- [Politique de confidentialité](https://eltrov52.github.io/edulink-congo-legal/politique-confidentialite.html)
- [Conditions générales d'utilisation](https://eltrov52.github.io/edulink-congo-legal/conditions-utilisation.html)

Ces adresses sont utilisées dans App Store Connect, sur le Play Store, et dans l'écran
« Profil » de l'application mobile.

---

**Ce dépôt est volontairement public, et ne doit contenir que ces pages.**

Il existe uniquement parce qu'Apple et Google exigent que ces deux textes soient accessibles
à une adresse web publique. Le code source d'EduLink Congo, ses spécifications et ses
documents de travail restent dans un dépôt privé séparé — ne rien ajouter ici qui n'ait
pas vocation à être lu par tout le monde.

Les versions Word de référence de ces deux textes sont conservées hors dépôt, avec les
autres documents du projet.
